# Release Notes

## 0.16.2

### What's New

- Added a dedicated Preferences surface with native menu integration.
- Added theme mode selection for Light, Dark, and Automatic appearance.
- Added palette selection for Default, IntelliJ Light, and IntelliJ Dark themes.
- Persisted zoom level, theme preferences, and working-directory defaults across launches.
- Added multi-window session restore for geometry and disk-backed documents when launching without a file.
- Added split edit/preview workflow refinements and related frontend/backend test coverage.
